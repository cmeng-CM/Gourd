壶中天 / Gourd

使用手册适用版本 0.5.0 · 适用系统 macOS 15（Sequoia）及以上 · Apple 芯片（arm64）（液态玻璃观感需 macOS 26，15 上自动降级为普通模糊）· 2026-10-28

壶中天是 macOS 上的「刘海工作台」：把屏幕顶部那一小块做成命令面板——媒体、日历、待办、通知、系统状态、文件暂存、快捷启动与自建小工具都收在这里，一切功能可开关。它是菜单栏小工具（没有 Dock 图标），鼠标移到屏幕顶部中间即展开。

1 · 安装与首次启动

安装（任选其一）

方式步骤
DMG（推荐）下载 Gourd-0.5.0.dmg → 打开 → 把「壶中天」拖进「应用程序」
命令行（装完无任何提示）curl -fsSL https://raw.githubusercontent.com/cmeng-CM/Gourd/main/install.sh | bash
脚本只做五件事：判断架构 → 下载 → 校验 SHA256 → 拷进「应用程序」→ 清理。装指定版本：| bash -s -- v0.5.0
覆盖升级新版「壶中天」拖进「应用程序」覆盖旧版；偏好、权限、登录项都不会丢
首次打开被拦下？应用未公证（本项目不付费走 Apple 开发者计划），第一次双击会被 Gatekeeper 拦——放行一次，之后不再拦：
  1. 双击「壶中天」，出现「Apple 无法验证」提示时点完成；
  2. 系统设置 → 隐私与安全性 → 往下滚到「安全性」→ 点仍要打开；
  3. 输密码，再双击一次即可。
别跳第 1 步：先被拦一次，「仍要打开」按钮才会出现。想完全避开，用上面的命令行方式装。

第一次启动会发生什么

  1. 引导窗（只出现一次）：选语言 → 相机 / 日历 / 音乐授权 → 选使用档位，走完即进主界面；
  2. 屏幕顶部多出一小块：刘海机型就是刘海本身；没有刘海的机型是一枚居中的虚拟胶囊。鼠标移上去悬停展开；
  3. 菜单栏多出图标：设置、退出在它的菜单里（图标可在设置里关——关掉后右键面板同样有「设置 / 退出」）。

2 · 快速上手：基本交互

想做的事怎么做

3 · 首页三带

带装什么能不能排
环境带（固定第一排）音乐 · 前台应用 · 系统读数（CPU / 内存 / GPU）三块相对先后跟着「首页组件」节的顺序走，但永远在第一排
今天带（宿主直渲）日期（公历 · 周日 · 农历 · 节假日）· 本月/本季/今年剩余工作日 · 下一个日程与倒计时 · 右端 ＋ 新增不能排、不能关（它没有开关）
可变流其余组件（默认是今日清单 + 通知），放不下换行完全按「首页组件」节的顺序

今日清单（今日清单块）

固定表头显示今日待办已办/总量与日程数量，下方滚动区先列日程（日历色条 + 标题 + 时间），再列待办（状态圈 + 标题）。点圈 = 完成 / 撤销完成；点条目就地弹出详情浮窗（不切页），浮窗底部图标动作可打开系统 App / 编辑 / 删除；行右端也常显 ✎ / 🗑。待办写回系统「提醒事项」。

前台应用

一整片图标网格（默认关，可在组件页开）。当前应用带白环排第一格，其余是打开着的 App——点一格就切过去。点了「没反应」有三种自动处理：窗口最小化/在别的屏 → 还原并切过去；一个窗口都没有 → 重新打开；已退出的 → 重新打开它。

4 · 日历与 AI 日程生成

月历入口 = 展开面板的「日历」页（开关在设置 → 组件 → 面板组件）。今天带右端的 ＋ 直接进新建页（默认日程，页内可切待办）。月历周一起始；日格右下角的点分色——橙色 = 你自己安排的日程（可写日历）、蓝色 = 节假日/农历节气（订阅日历）；右上角橙色角标 = 该日你的日程数量。

看与维护

  • 点整行就地弹出详情浮窗：完整标题 / 起止 / 地点 / 备注 + 底部图标动作（▦ 打开系统日历 / ✎ 编辑 / 🗑 删除）。收起浮窗：点 ×、再点同一行、Esc、切页或收面板。
  • 删除必须确认（半透明遮罩 + 居中卡片，点「删除」才真删，会同时删系统记录）。重复日程、会议邀请、生日与只读日历由系统应用维护，岛内不给编辑/删除入口。
  • 左侧四视图（今天 / 最近 7 天 / 清单 / 已完成）；悬停只高亮，点击替换右栏。

新增 / 编辑（一张两列表单）

  1. 右栏列表顶部 ＋（或今天带 ＋、待办块 ✎）：选「待办」或「日程」；
  2. 表单字段两列并排：目标｜全天、开始｜结束、地点｜链接（待办是「截止｜链接」），标题与备注整宽；日期取月历选中日，可跨日、可全天（全天结束日期显示包含的最后一天）；
  3. 保存只校验标题非空 + 可写目标；日期时间由你自己在表单里核对；
  4. 返回 ≠ 取消：左上返回或 Esc 暂存草稿回前一页；「取消」是放弃（有修改先确认）。切页 / 收回后从列表「有未保存的日程 · 继续编辑」可恢复；草稿仅本次运行保留。

用 AI 从一句话生成日程

先在 设置 → 集成 → AI 模型 配置供应商 / 接口地址 / 密钥 / 模型（支持 OpenAI compatible / Anthropic / Gemini / Ollama，本机模型也行）。API Key 只存本机应用数据目录（目录 0700 / 文件 0600），不进代码、日志或安装包。
  1. 新建日程时，在多行原文区粘贴或输入一句话（例如「明天下午三点在会议室 A 开迁移方案评审，大概一小时」）；
  2. 点生成或按 ⌘↩——输入不会触发生成，只有你点了才发；日程请求会关闭模型思考模式，返回更快；
  3. 模型直接理解原文返回规范的日期 / 时间 / 地点 / 链接，不要求固定格式；结果填成草稿，仍可逐项修改；
  4. 生成失败只留一行红字「生成失败：原因」+ 重试（同一枚按钮换文案）+ 改为手工填写，不会写坏你已填的内容；只有点保存才写系统日历。

起点明确且原文没有结束提示时默认一小时；「周会」不会创建重复；日期时间按草稿来源时区编辑，异于本机时显示来源时区。

5 · 会议一键入口

当通知 / 日程 / 待办被认出含会议信息（华为云会议、腾讯会议、化小易等），条目旁出现一枚 22pt 图标按钮，一次点击就是结果：

  • 有可打开的入口就打开会议（华为 cloudlink / 腾讯 wemeet 深链，华为深链会带上原文里的入会密码）；
  • 只有会议号时复制会议号；打开被系统拒绝则退回复制，不会谎称已加入；
  • 结果由图标本身表达：点击中转圈、成功打勾、失败感叹号；
  • 多个候选不猜：有一条以上可打开候选时点一下会弹菜单让你选；右键最多 4 项（复制会议号 / 各平台打开 / 复制邀请原文）；
  • 识别完全由本地规则完成，不把原文发给模型。

6 · 通知

通知有三个面：折叠态铃铛（未读计数）、首页通知块（列已保留的通知，最多 40 条，块内滚动、可视 6 行）、展开面板的完整列表。点条目打开对应 App 并收起面板。

  • 全部清除：只清岛上的列表，不动系统通知中心；
  • 条目右侧 × 只移除这一条；近 10 秒内出现的通知会连同系统横幅一起关掉（按钮提示会写明是哪一种）；
  • 通知浮层：新通知在屏幕上浮出 8 秒提示，默认只上主屏；表头那枚多屏开关 = 设置里「在外接显示器上也显示」同一颗，下一条通知即生效；
  • 列表与浮层读系统通知库，需要完全磁盘访问（系统设置 → 隐私与安全性 → 完全磁盘访问，勾上壶中天后重启应用）；没给时显示「不可读」，属正常降级。

7 · 启动台

  • 右键 = 固定 / 取消固定，也可以直接拖拽：拖到「快捷启动」区固定、拖到下区取消；「快捷启动」内部可拖动排序（落点即目标格，重启保持）；
  • 点图标启动并自动收起面板；
  • 设置（组件卡片上）：图标大小（28–96）、间距倍率、按最近使用排序。

8 · 音乐与屏幕歌词

首页音乐块显示正在播放：封面 + 曲名 + 进度 + 控制键（有播放会话时才出现）。点一下这块音乐 = 打开此刻正在放歌的那个音乐软件（放的是谁就开谁）——整块都是命中区，只有进度条和控制键各管各的。

屏幕歌词（默认关）

歌词不在面板里：开了「媒体 → 屏幕歌词」，岛收起时歌词显示为桌面悬浮层（默认贴在岛下方居中，拖到哪记住哪，展开岛即隐藏）。没有歌词就不显示——不出占位文案。

取词规则（会先问本机播放器，再问公共词库）：① 先读本机播放器自己的歌词缓存（LX Music 放过的歌直接用，离线且与播放器一致）；② 没有，再去 LRCLIB：按「歌名 + 歌手」问，歌手别名 / 团体后缀 / 多歌手 / 歌名版本标注会自动换写法重试；③ 最后只按歌名 + 时长吻合（±3 秒）认领。词库瞬时故障（503）不算「没有歌词」，20 秒后自动再试。

可调：字体（12–30pt）、行数（1/3/5）、不透明度、颜色（跟随封面 / 白 / 自定义）、高亮当前行、锁定位置（鼠标穿透）。

13 · 常见问题

找不到应用？

它是菜单栏小工具（没有 Dock 图标）。点菜单栏图标，或把鼠标移到屏幕顶部中间悬停展开。

怎么完全退出？

菜单栏图标 → 退出；或右键面板 → 退出（菜单栏图标关掉后这是唯一出口）。

首页少了块、条尾有 ＋N？

面板宽度不够时按顺序从尾部丢块，＋N 悬停会列出被丢的块名——拉宽面板（右下角小圆点）即可。

月历上没有节假日？

农历一直有（日格第二行，初一显示月名）。节假日要在系统「日历」里订阅节假日日历（如「中国大陆节假日」）；另检查「隐藏全天事件」——节假日是按全天条目读的。

点了通知的 ×，系统通知还在？

只有近 10 秒内还能抓到系统横幅的通知才连同系统那条一起关；更早的只从岛上列表移除。

有自动更新吗？

没有。用新 DMG 覆盖安装或重跑命令行脚本即可，偏好、权限、登录项都不丢。例外：AI 的 API Key 从 0.3.0/0.4.0 升上来需要在「设置 → 集成 → AI 模型」重输一次（Key 存储方式变更）。

界面里有些英文？

少数上游页面保留英文（如「控制」页材质下拉），主体已中文化。

日志在哪？
