## 1. 安装与首次启动

### 安装（四种方式，任选）

| 方式 | 步骤 |
|---|---|
| **DMG**（推荐给使用者） | 下载 `Gourd-0.2.0.dmg` → 打开 → 把「壶中天」拖进「应用程序」 |
| **命令行**（装完无提示） | `curl -fsSL https://raw.githubusercontent.com/cmeng-CM/Gourd/main/install.sh \| bash` |
| **自己构建**（开发机） | 仓库里执行 `sh tools/build.sh --install`（直接装到 `/Applications/壶中天.app`），或 `sh tools/build.sh --dmg` 出安装包 |
| **覆盖升级** | 把新版「壶中天」拖进「应用程序」覆盖旧版即可；偏好、权限、登录项都不会丢 |

要求：**macOS 26（Tahoe）及以上**、**Apple 芯片（arm64）**。

**首次打开被拦下怎么办**：应用**未公证**（本项目不付费走 Apple 开发者计划），第一次双击会被 Gatekeeper 拦——**放行一次，之后不再拦**：

1. 双击「壶中天」，出现「Apple 无法验证」这类提示时点**完成**；
2. **系统设置 → 隐私与安全性** → 往下滚到「安全性」一栏 → 找到刚被拦下的应用 → 点**仍要打开**；
3. 输入密码，再双击一次即可。

> 别跳第 1 步：先试一次被拦下，「仍要打开」按钮才会出现在系统设置里。
> 想完全避开这一步，用上面的**命令行**方式装（从浏览器下载会被打上隔离标记，`curl` 不会）。

### 第一次启动会发生什么

1. **引导窗**（只出现一次）：选语言 → 相机 / 日历 / 音乐授权 → 选使用档位，走完即进主界面；
2. **屏幕上多出一小块**：刘海机型就是刘海本身；没有刘海的机型是一枚**居中的虚拟胶囊**。鼠标移上去**悬停展开**；
3. **菜单栏多出图标**：设置、退出都在它的菜单里。

## 2. 界面速览

### 收起态

不占地方的一小块：左边是**待办**（默认占中央槽位）、右边是**通知**铃铛；有计时器、下载、录屏、勿扰等状态时也在这里显示。播放音乐且开了「媒体 → 屏幕歌词」时，**岛下方的桌面上**会出现一层歌词**悬浮层**（岛一展开就隐藏，位置可拖拽记忆；面板里不再显示歌词）。

### 展开面板

鼠标移到顶部中间即展开（也可用 `⌘⇧I`）。面板自上而下是四段：

1. **标签栏**——顶部一排 tab：主页 / 文件暂存 / 终端 / 待办 / 通知 / 日历 / 启动台 / 计时器……**出现哪些取决于你开了哪些功能**；右侧是固定的几个按钮：**镜子** / 剪贴板 / 取色 / 计时器 / 设置。『文件暂存』那枚 tab 的图标是 macOS 隔空投送样式的同心弧；
2. **环境带**——固定第一排：音乐、前台应用（一整片图标网格）、CPU / 内存 / GPU 三行读数；
3. **今天带**——日期（含农历与节假日）、本月 / 本季 / 今年剩余工作日、**下一个日程与倒计时**；
4. **可变流**——其余组件（今日清单、通知……），**默认显示哪些、先后顺序都在设置 → 组件里**（见 [组件页与各模块](modules.md)）。

面板宽高可拖拽调整（展开态**右下角的小圆点**）；「面板布局 = 自适应」时高度跟着内容走，拖拽把手不生效。

### 交互

| 想做的事 | 怎么做 |
|---|---|
| 开关面板 | 悬停展开 / 移开收起；`⌘⇧I` 也行 |
| 看完今天的日程和待办 | 首页今日清单向下滚动；计数头固定，日程与待办分组，浏览日历其它日期不影响今天 |
| 完成待办 / 看完整内容 | 首页点圈完成或撤销，点标题进入日历详情；详情可滚到长备注末尾，返回恢复来源与滚动位置 |
| 新增或修改日程 | 日历页右栏 `＋` 新增待办/日程；普通可写日程在详情编辑或确认删除，重复、会议、生日、只读等交给系统应用（见 [各模块操作](modules.md)） |
| 暂存日历输入 | 返回或 `Esc` 暂存；切页或收回后从日历列表「继续编辑」恢复。「取消」是放弃，有修改会先确认 |
| 带草稿退出 / 重启 | 有修改时选保存、放弃或取消；正在提交先等待，失败则取消退出。草稿仅本次运行保留，强制退出不能恢复 |
| 拖文件进岛暂存 | 直接把文件拖到刘海上（暂存器，默认开） |
| 关掉某块 / 调顺序 | 设置 → 组件（见 [组件页与各模块](modules.md)） |
| 改每一项设置 | 设置窗（见 [设置参考](settings.md)） |

## 3. 权限清单

**缺哪个权限，哪条功能就降级——不会崩。** 权限都是按需弹窗，也可以自己去系统设置里补。

| 权限 | 谁在用 | 什么时候问 |
|---|---|---|
| 日历、提醒事项 | 日历页、首页的今天带与今日清单；待办模块读写的也是「提醒事项」 | 首次读日历 / 待办时 |
| 摄像头 | 首页「镜子」块 | 打开镜子块时 |
| 通知 | 计时器到点、通知相关浮层 | 首次需要发通知时 |
| **完全磁盘访问** | **通知模块**读系统通知库（没有它时通知块显示「不可读」，属正常降级）、**暂存器的全局模式** | 手动到「系统设置 → 隐私与安全性 → 完全磁盘访问」勾选 |
| 辅助功能 | 通知的「同时关掉系统通知」、媒体键 / 亮度键拦截、**计时器同步系统时钟** | 用到时按提示给 |
| 定位 | 锁屏天气小组件 | 首次显示天气时 |
| 屏幕录制 / 麦克风 | 屏幕助手（截图能力）、实时音频波形 | 打开对应功能后按提示给 |
| 音频采集 | 音乐块的实时波形（默认关） | 第一次播放且开了波形时 |

> 这些功能都是**本地实现**的：媒体走系统框架与子进程、通知读本机通知库、镜子直接开摄像头。**本项目不新增任何出站请求、不上传数据**；联网项（歌词、锁屏天气）按各自开关生效。

## 5. 更新与卸载

### 更新

**没有应用内更新**（关于页的「检查更新」不可用）：三条路任选——重新跑一遍命令行安装脚本、用新 DMG 覆盖安装，或开发机上重新 `sh tools/build.sh --install`。

**偏好不会丢**：设置、模块开关、顺序、历史都按 Bundle ID 存在偏好里；**系统权限也不会重问**（授权按「签名证书 + Bundle ID」记忆）。

### 卸载

把「壶中天」拖进废纸篓即可。想连痕迹一起清掉，再按需删这几处（**都是可选的**）：

| 位置 | 内容 |
|---|---|
| `~/Library/Preferences/com.cmeng.gourd.plist` | 主偏好（从源码构建的调试版是 `com.cmeng.gourd.dev.plist`） |
| `~/Library/Preferences/com.cmeng.gourd.module.*.plist` | 各模块自己的配置（例如启动台的图标大小） |
| `~/Library/Logs/Gourd/` | 运行日志 |
| 系统设置 → 通用 → 登录项 | 开过「登录时启动」会有一条 |
| 钥匙串访问 | 登录过 Spotify 一类第三方服务会留下一条令牌；删掉就要重新登录 |
