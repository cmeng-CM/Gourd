## 1. 安装与首次启动

### 安装（三种方式，任选）

| 方式 | 步骤 |
|---|---|
| **DMG**（推荐给使用者） | 下载 `Gourd-0.1.0.dmg` → 打开 → 把「壶中天」拖进「应用程序」 |
| **自己构建**（开发机） | 仓库里执行 `sh tools/build.sh --install`（直接装到 `/Applications/壶中天.app`），或 `sh tools/build.sh --dmg` 出安装包 |
| **覆盖升级** | 把新版「壶中天」拖进「应用程序」覆盖旧版即可；偏好、权限、登录项都不会丢 |

第一次打开若被 Gatekeeper 拦下（应用未公证）：右键 → **打开**，或到「系统设置 → 隐私与安全性」点「仍要打开」。

### 第一次启动会发生什么

1. **引导窗**（只出现一次）：选语言 → 相机 / 日历 / 音乐授权 → 选使用档位，走完即进主界面；
2. **屏幕上多出一小块**：刘海机型就是刘海本身；没有刘海的机型是一枚**居中的虚拟胶囊**。鼠标移上去**悬停展开**；
3. **菜单栏多出图标**：设置、退出都在它的菜单里。

## 2. 界面速览

### 收起态

不占地方的一小块：左边是**待办**（默认占中央槽位）、右边是**通知**铃铛；有计时器、下载、录屏、勿扰等状态时也在这里显示。

### 展开面板

鼠标移到顶部中间即展开（也可用 `⌘⇧I`）。面板自上而下是三段：

1. **首页块**——一行行的小块，每块一件事：音乐、前台应用、通知、待办、进度统计、CPU / 内存 / GPU 三环……**默认显示哪些、先后顺序都在设置 → 组件里**（见 [组件页与各模块](modules.md)）；
2. **整宽日历行**——左边整月网格（含农历、订阅的节假日）、右边当天清单；**不想要就在设置 → 日历关掉「显示日历」**；
3. **标签栏**——顶部一排 tab：主页 / 文件暂存 / 终端 / 待办 / 通知 / 日历 / 启动台 / 计时器……**出现哪些取决于你开了哪些功能**；右侧是固定的几个按钮：剪贴板 / 取色 / 计时器 / 设置。

面板宽高可拖拽调整（展开态**右下角的小圆点**）；「面板布局 = 自适应」时高度跟着内容走，拖拽把手不生效。

### 交互

| 想做的事 | 怎么做 |
|---|---|
| 开关面板 | 悬停展开 / 移开收起；`⌘⇧I` 也行 |
| 拖文件进岛暂存 | 直接把文件拖到刘海上（暂存器，默认开） |
| 关掉某块 / 调顺序 | 设置 → 组件（见 [组件页与各模块](modules.md)） |
| 改每一项设置 | 设置窗（见 [设置参考](settings.md)） |

## 3. 权限清单

**缺哪个权限，哪条功能就降级——不会崩。** 权限都是按需弹窗，也可以自己去系统设置里补。

| 权限 | 谁在用 | 什么时候问 |
|---|---|---|
| 日历、提醒事项 | 日历行与日历页；待办模块读写的也是「提醒事项」 | 首次读日历 / 待办时 |
| 摄像头 | 首页「镜子」块 | 打开镜子块时 |
| 通知 | 计时器到点、通知相关浮层 | 首次需要发通知时 |
| **完全磁盘访问** | **通知模块**读系统通知库（没有它时通知块显示「不可读」，属正常降级）、**暂存器的全局模式** | 手动到「系统设置 → 隐私与安全性 → 完全磁盘访问」勾选 |
| 辅助功能 | 通知的「同时关掉系统通知」、媒体键 / 亮度键拦截、**计时器同步系统时钟** | 用到时按提示给 |
| 定位 | 锁屏天气小组件 | 首次显示天气时 |
| 屏幕录制 / 麦克风 | 屏幕助手（截图能力）、实时音频波形 | 打开对应功能后按提示给 |
| 音频采集 | 音乐块的实时波形（默认关） | 第一次播放且开了波形时 |

> 这些功能都是**本地实现**的：媒体走系统框架与子进程、通知读本机通知库、镜子直接开摄像头。**本项目不新增任何出站请求、不上传数据**；联网项（歌词、锁屏天气）按各自开关生效。

## 5. 更新与卸载

### 更新

**没有应用内更新**（关于页的「检查更新」不可用）：用新 DMG 覆盖安装，或重新 `sh tools/build.sh --install`。

**偏好不会丢**：设置、模块开关、顺序、历史都按 Bundle ID 存在偏好里；**系统权限也不会重问**（授权按「签名证书 + Bundle ID」记忆）。

### 卸载

把「壶中天」拖进废纸篓即可。想连痕迹一起清掉，再按需删这几处（**都是可选的**）：

| 位置 | 内容 |
|---|---|
| `~/Library/Preferences/com.cmeng.gourd.plist` | 主偏好（从源码构建的调试版是 `com.cmeng.gourd.dev.plist`） |
| `~/Library/Preferences/com.cmeng.gourd.module.*.plist` | 各模块自己的配置（例如启动台的图标大小） |
| `~/Library/Logs/Gourd/` | 运行日志 |
| 系统设置 → 通用 → 登录项 | 开过「登录时启动」会有一条 |
| 钥匙串访问 | 登录过 Spotify 一类第三方服务会留下一条令牌；删掉就要重新登录 |
