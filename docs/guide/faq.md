# 常见问题

## 装在哪儿、怎么打开

**没有 Dock 图标，找不到应用？** 它是**菜单栏小工具**（`LSUIElement`），不占程序坞。打开方式有二：点**菜单栏图标**，或把鼠标移到**屏幕顶部中间**（刘海 / 刘海位）——悬停即展开。退出也在菜单栏菜单里。

**第一次打开被 Gatekeeper 拦下？** 应用**未公证**（本项目不付费走 Apple 开发者计划），第一次双击一定会被拦——**放行一次，之后不再拦**：

1. 双击「壶中天」，出现「Apple 无法验证其是否包含恶意软件」这类提示时点**完成**；
2. **系统设置 → 隐私与安全性** → 往下滚到「安全性」一栏 → 找到刚被拦下的应用 → 点**仍要打开**；
3. 输入密码，再双击一次即可。

> 别跳第 1 步：先试一次、被拦下，「仍要打开」按钮才会出现在系统设置里。
> 想完全避开这一步，用命令行装：`curl -fsSL https://raw.githubusercontent.com/cmeng-CM/Gourd/main/install.sh | bash`（`curl` 下载不带隔离标记，首启不会弹）。

## 首页与面板

**首页少了块，条尾还有个 `＋N`？** 面板宽度不够时按顺序从**尾部丢块**，`＋N` 就是「还有几块没显示」，把鼠标移上去会列出被丢的块名。**拉宽面板**是唯一的办法（拖动展开态右下角的小圆点）。正常情况下紧凑块会**换行**、一块都不丢——只有连一行都放不下才会丢。

**拖动右下角的小圆点改不了高度？** 「面板布局」在**自适应**档时高度由内容决定，拖拽把手不生效（高度跟着内容走）。想手动定高：设置 → 外观 → 面板布局 → 改「手动」，再用滑杆或拖拽把手。

**面板太矮时谁先消失？** 让位顺序是：先收起日历行 → 再收起主块带 → 最后才动小组件块。所以最先看不见的是日历行。

**某个模块「开了却没反应」？** 组件页每张卡片上有一行**效果说明**（开了会在哪看到什么），先照它找位置。带「**由上游设置管理（改了不生效）**」的项，真源在设置里的另一页——卡片上那个开关与它是同一个，在哪儿拨都一样。另外有几处是「互斥」的：**日历与侧边歌词二选一**（「侧边显示歌词」开着时日历开关会灰掉）、**计时器的 tab 只在「显示方式 = 标签页」时出现**。

## 通知

**通知块 / 列表显示「不可读」？** 需要**完全磁盘访问**（设置 → 隐私与安全性 → 完全磁盘访问，勾上壶中天；改完重启应用）。不给权限也能用，只是通知相关功能降级——不会崩。

**点了通知的 `×`，系统里的通知还在？** 只有**近 10 秒内**还能抓到系统横幅的通知，才会连同系统那条一起关掉；更早的（或从数据库读到历史的）只能从列表移除。按钮提示会如实写是哪一种。

**「一键清除」会清掉系统通知中心吗？** 不会。它只清岛上的列表。

## 权限与隐私

**为什么要摄像头 / 完全磁盘访问 / 辅助功能这类权限？** 这些功能都是**本地实现**的：媒体走系统框架与子进程、通知读本机通知库、镜子直接开摄像头、计时器同步读系统状态项（要辅助功能）。**本项目不新增任何出站请求、不上传数据**；联网项（歌词、锁屏天气）按各自开关生效。

**权限可以不给吗？** 可以。缺权限只会让对应功能降级（通知显示「不可读」、镜子显示降级文案、暂存器开关变灰），不会崩溃。

**锁屏天气的位置是哪来的？** 走系统定位（首次会问一次）；天气数据源可在「锁屏」页切换（Open Meteo / wttr.in）。

## 日历与农历

**月历上为什么没有农历 / 节假日？** 农历一直有（每个日格第二行，初一显示月名）。**节假日**需要你在系统「日历」里**订阅**节假日日历（如「中国大陆节假日」）——没订阅就只显示农历，不算故障。

**节假日名突然不见了？** 检查「隐藏全天事件」：节假日是按全天条目读的，打开它会一起隐藏。

## 待办

**首页的「今天」和面板里的「今天」对不上？** 首页块的表头是**今日已办 / 总量**，面板里的「今天」是同一份聚合——两处口径一致。若数字看着怪，先确认系统「提醒事项」里的完成状态（本应用读写的就是它）。

**待办写回失败？** 面板上会出现一行橙字提示（写系统提醒失败）；未授权时整页是权限引导。

## 其他

**版本号为什么是 0.1.0？** 它表示「第一个冻结的自用版」：功能面已成型，但仍有已知的待接管线（见仓库里的开发文档）。不把它报成 1.0.0 是为了不误导。

**有自动更新吗？** 没有。**本版本不使用应用内更新**（关于页的「检查更新」不可用），升级方式见手册首页的「更新与卸载」——用新 DMG 覆盖安装即可，偏好、权限、登录项都不会丢。

**应用内有些页面的选项是我看不懂的英文？** 那几处是上游原样保留的（例如「控制」页的材质下拉、实时活动页的 Notification HUD 一节）——本版本只翻译了界面的主体，这些留待后续批次。

**日志在哪？** `~/Library/Logs/Gourd/`（模块探针日志）；「锁屏」页底部还有「复制最新崩溃报告」，反馈问题时用得上。
