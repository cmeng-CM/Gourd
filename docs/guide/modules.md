# 组件页与各模块

**组件页 = 本应用的总控台**（设置 → 媒体与显示 → 组件）：所有功能一页管完——开关在哪、在哪儿出现、先排谁、能配什么。

**内置块今天一个都不剩**（2026-10-11 起）：页面上的每一张卡都是模块。

首页与日历交互按 2026-10-12 当前源码说明；此前首页滚动与返回、详情全文已有界面实测通过。本轮草稿所有权修复已通过完整单元测试；界面验收已由作者人工逐项复核通过（2026-10-12），两次界面定向探针仍停在测试 Runner 初始化超时、目标用例没有执行，自动化 UI 套件在本机受该超时限制未跑。本轮 Release 已按用户要求在本地安装到 `/Applications/壶中天.app`（安装不代表界面验收通过）；实施与各版本验证状态见 [轻量交互设计记录](../39-calendar-light-interactions.md)。

## 首页长什么样（2026-10-11 起：三带）

首页自上而下是**三条带**：

| 带 | 装什么 | 能不能排 |
|---|---|---|
| **环境带**（固定第一排） | **音乐 · 前台应用 · 系统读数**（CPU / 内存 / GPU） | 三块的**相对**先后跟着「首页组件」节的顺序走，但它们永远在第一排——多开别的组件不会把它们挤下去 |
| **今天带**（宿主直渲，不是组件） | 日期（公历 · 周日 · 农历 · 节假日）· **本月/本季/今年剩余工作日** · **下一个日程**与倒计时 | 不能排、不能关（它没有开关，就是一条排版） |
| **可变流** | 其余组件（今天是**今日清单 + 通知**），放不下换行，行高按行内最高的块 | 完全按「首页组件」节里的顺序 |

第一排里**前台应用会吃掉多余的宽度**（面板越宽，它一行能放的图标越多）；今日清单与通知同理——关掉其中一个，另一个就铺满整行。

## 两节的分工

| 节 | 管什么 | 关掉它意味着 |
|---|---|---|
| **首页组件** | 首页上有没有这个块、块的先后（↑↓）。排序按**环境带**与**可变流**分两组呈现，只能在组内用 ↑↓ 调整，不能跨组 | 这个块的**首页面**消失；模块的另一面（展开面板的 tab 等）照常——**两节互不影响** |
| **面板组件** | 要不要单独出一个展开面板 tab、tab 的先后（↑↓） | 这个模块的**面板面**消失；首页块照常 |

只有一面可关的模块（统计 / 待办 / 通知 / 音乐 / 前台应用——只声明首页块的，关掉就是关掉模块本身）；启动台 / 快捷指令 / 计时器只声明了面板 tab，关掉同理。

每张卡片上有：图标、名称、**出现在哪**的徽标（首页 / 展开面板 / 折叠态 / 锁屏）、效果一行（「开了会在哪看到什么」）、「默认关闭」标记（默认关的模块）、一句摘要、**能直接拨的配置**（滑杆 / 开关 / 胶囊多选 / 数字框）、以及两种情况下的灰字：

- **由上游设置管理（改了不生效）**——这一项的真源在别处（面板上的**同一个开关**在那里也能拨，本卡片只是显示状态）；
- **启动失败；重启应用后再打开一次这个开关**——模块启动时出错了，开关会置灰。

**顺序与显隐怎么存的**：每节的 ↑↓ 写的是整表序号，拨完即时生效、重开也保持；关掉某一面写的是「摘除名单」（不会动模块本身）。两节的顺序各存各的，互不干扰。

## 逐模块

### 工作日统计（**已退休**，2026-10-11）

原来的首页块（工作时间进度 + 本周 / 本月剩余工作日）**退场了**：它的读数搬进了首页**今天带**右侧那一行小字（`本月剩 15 天 · 本季剩 59 天 · 今年剩 59 天`），而它占的那一大块面积换给了今日清单与通知。组件的文件还在库里（可逆），但不再注册——组件页因此没有这张卡，它的四项配置（显示的尺度 / 上下班时间 / 工作日）也随之不再可配。

> 今天带那一行按**默认工作日（周一–周五）+ 内置节假日表（2026）**算，不读上面那三项配置。

### 待办（折叠态中央槽位 + 首页块 + 展开面板 · 默认开）

首页块是**「今天」的完整清单**：固定表头显示今日待办已办/总量与日程数量，下方一条滚动区先列**日程**（日历色条 + 标题 + 时间），再列**待办**（状态圈 + 标题，已完成置灰划线）。条目多时向下滚动可看完；浏览日历中的其它日期不改变首页的今天数据，跨日但今天仍在进行的日程也在其中。没有日程也没有待办、且提醒权限已就绪时显示「今天没有安排」。折叠态中央是待办；展开面板里是一整页待办。

**首页点圈 = 完成 / 撤销完成**，不会打开详情；写入失败保留原状态并显示错误。点独立详情箭头进入日历右栏详情；正文可拖选或右键复制标题、完整信息、会议信息，返回首页恢复原来的滚动位置；需在「面板组件」中开启日历页才能打开详情。开了「隐藏已完成提醒」时完成的行消失，固定表头仍显示完整的已办/总量；当前行被隐藏时滚动位置移到邻近条目。

**待办写的是系统「提醒事项」**——新增 / 完成 / 删除写回同一条系统记录；日程的修改与删除在日历页进行。首页的「隐藏全天事件」与日历显示偏好一致。

卡片上没有配置项（权限提示在 tab 里交互）。

**在面板里能做的事**：左侧四视图（今天 / 最近 7 天 / 清单 / 已完成，各带计数）；顶部 `+` 新增（标题 + 今天/明天/无日期）；每行点圈完成、点**优先级胶囊**循环「无 → 低 → 中 → 高」、悬停出垃圾桶（删除时弹确认，会同时删掉系统提醒里的那一条）。

### 通知（折叠态铃铛 + 首页块 + 展开面板 · 默认开）

首页块列**已保留的全部通知**（标题行如实写「通知 · 最近 N 条」，与列表里画出的条数同源），列表在一个**块内滚动区**里，能同时看到 6 行、更多时向下滚动可看完（块高不变，与今日清单块同一套滚动交互）；每条两行：第一行「App 名 · 相对时间」，第二行「标题 · 正文预览」（单行截断，完整正文在展开列表里）；折叠态一枚铃铛；展开面板是完整列表。点条目**打开对应 App 并收起面板**。

| 可配置项 | 默认 | 说明 |
|---|---|---|
| （无） | — | 列表列出全部已保留通知（最多 40 条），可视 6 行、其余滚动查看；完整列表在 tab 里 |

**在面板里能做的事**：列表每行右侧的 `×` 只把这一条从列表移除；**近 10 秒内**出现过的通知（还能抓到系统横幅）会连同系统通知一起关掉——按钮提示会如实写是哪一种。底部还有一行说明能力边界。列表需要**完全磁盘访问**，没给时这里显示「不可读」的提示（属正常降级）。

### 前台应用（首页块 · **默认关**）

首页块是**一整片图标网格**：一行放多少格由块拿到的宽度决定（面板越宽越多，最多 16 格），能画几行由高度决定；**当前应用是其中的第一格**（带一圈白环），其余是其它打开着的 App——点一格就切过去，悬停出名字。装不下的在行尾给一个 `…`（悬停能看到还差几个）。显示多少**与同一行的其它块无关**（块高由自己申报）。

> **点了「没反应」怎么办？** 现在按三种情况分别处理：窗口**最小化或在别的屏幕**（比如接过外接显示器、拔掉之后窗口留在那边）→ 点一下把它**还原并切过去**；应用**一个窗口都没有**（关掉了所有窗口，比如访达 / 终端）→ 点一下替你**重新打开**（和「程序坞」点它一样，会开出新窗口）；**已经退出**、还留在格子里的 → 也会重新打开它。少数应用的窗口不在当前屏幕、自己又不响应「重新打开」时，仍可能什么都看不到——那种情况第三方进程没有别的办法。

| 可配置项 | 默认 | 说明 |
|---|---|---|
| 显示最近应用条数 | 5 | 最近应用的记忆条数（3–8，决定排序参考）；块里画几格由块的大小决定 |

### 启动台（展开面板 · **默认关**）

一个可搜索、可固定的应用网格：搜索框输入即过滤；**右键 = 固定 / 取消固定**，也可以**拖拽**——拖到「快捷启动」区固定、拖到下区取消；点图标启动并自动收起面板。

| 可配置项 | 默认 | 说明 |
|---|---|---|
| 图标大小 | 44 | 格子目标宽（28–96） |
| 图标间距 | 1.0 | 间距倍率（0.6–1.6） |
| 按最近使用排序 | 开 | 用系统「最近使用」排序；关掉按名称排（**改完要重开模块或重启应用**） |

### 快捷指令（展开面板 · **默认关**）

把系统「快捷指令」搬进面板：搜索、固定（右键）、运行，输出可回显；有超时保护。

| 可配置项 | 默认 | 说明 |
|---|---|---|
| 回显运行输出 | 关 | 运行时把快捷指令的输出显示在结果行 |
| 运行限时（秒） | 30 | 单次运行的超时（超时只终止 `shortcuts` 进程本身，它拉起的动作不保证一起结束） |

### 统计（首页块 · **默认关**）

首页块是**三行读数**（窄窄一列）：CPU / 内存 / GPU 各一行「指标色圆点（外圈那道弧是按用量的进度）+ 名称 …… 百分比」。开关就是它自己；完整的图表、刷新间隔、温度单位等在**设置 → 统计**页。

卡上还会看到「**由上游设置管理（改了不生效）**」：那几项（CPU / 内存 / GPU 图表的可见性）服务于设置页的完整图表，不影响首页这一行。

首页块显示正在播放：小封面（可选）+ 曲名 + 进度 + 控制键。**有播放会话时才出现**（可在「媒体」页关掉「自动隐藏不活跃的刘海媒体播放器」让它常驻）。

| 可配置项 | 默认 | 说明 |
|---|---|---|
| 显示封面 | 关 | 画不画那块 36pt 的小封面 |

> 卡片上的「由上游设置管理」两项（播放器取色、可视化器）服务于面板里的播放器外观，在「外观」页那一组里改。

### 镜子（**顶栏按钮 · 浮动镜子**，2026-10-11 起不再占首页组件）

**点面板右上角那枚摄像头按钮**，面板上浮出一块方镜（200 × 200，浮在首页内容之上），再点一次收起（收起时顺手停掉摄像头，不看了就不占着）。

之前那个「首页块」形态已退休（读的是同一路摄像头）。**镜子没有自己的组件卡**：开关、形状、摄像头选择都在**设置 → 外观 → 附加功能**那一节里（`显示镜子` / `Mirror shape` / `Mirror Camera`）。

第一次用会请求摄像头权限；没授权时浮层里显示一行降级文案（点它一次也会再请求一次），授权后再点按钮就出画面。

### 计时器（展开面板 · 默认开）

展开面板的计时器页：预设 + 自定义倒计时；收起面板后计时继续跑。

> 卡上三项（总开关、显示方式、预设清单）由上游设置管理——在**设置 → 计时器**页里改。注意：只有「计时器控制显示为 = 标签页」时这里才会真的出现 tab（选「弹出窗口」时控件在收起态的按钮旁）。

### 日历（展开面板 · 默认开）

**首页那条「日历行」已退休**（2026-10-11）：首页现在由「今天带 + 今日清单」说清今天的事（用户反馈月历与第一排内容重复）。**月历入口 = 展开面板的「日历」页**，开关在「**面板组件**」节。月历**周一起始**（表头 一…日）。

左侧保留月历，右侧在**列表、详情、编辑**三个页面间切换。**编辑档**时左栏让位成 260pt 的**当日清单**（顶部一个「回到月历」按钮切回列表，下面是选中日的日程与待办，提醒可直接勾选完成 / 撤销，条目多时清单在栏内滚动），面板布局为**自适应**时整块面板也跟着变高（编辑时一屏能放完链接和备注；**手动**高度下面板高固定不变、不随页面变化）；列表档与详情档的左栏仍是整月网格。日格右下角的点分色——**橙色 = 你自己安排的日程**（来自可写的日历）、**蓝色 = 节假日/农历节气**（来自订阅日历）；**右上角橙色角标 = 该日你的日程数量**。列表条目是卡片：标题最多 2 行（开了「显示完整事件标题」就不限行），全天条目排在最前，条目多时栏内滚动；提醒的完成圈与标题分别操作。悬停只高亮，**点击独立详情箭头替换右栏为详情**，正文可拖选和右键复制，完成圈、详情与会议动作各自独立。页面头与底部动作固定，中间的列表、详情和表单各自可滚动。

**详情与维护**：详情显示完整标题、起止日期时间、地点和备注，长备注可以滚到底。底部可「打开系统日历 / 提醒」，提醒可完成或撤销完成；设置了第三方日历时，日程打开入口沿用该设置。普通可写日程可编辑标题、起止日期时间、全天、地点、备注和目标日历，也可删除；删除先在右栏确认标题与日期，成功回到来源附近。重复日程、分离出来的单次事件、会议邀请、生日和只读日历由系统应用维护，岛内不给编辑/删除入口；已保存提醒的完整编辑也交给系统「提醒事项」。

**新增入口**：右栏列表顶部 `＋` 打开编辑页，选择「待办」或「日程」，填写标题并选择可写目标列表/日历。三种入口（新建日程 / 新建待办 / 编辑日程）共用**同一个表单**：字段两列并排——「目标｜全天」「开始｜结束」「地点｜链接」，标题与备注各占整宽，待办只有「截止」一格、也没有地点；类型控件新建时可点、编辑日程时锁定（已保存的待办在系统「提醒事项」里改）。初始日期取月历选中日，之后可以在表单里改；日程明确分为开始与结束日期时间，可跨日，也可选全天。全天的结束日期显示**包含的最后一天**。保存成功显示新记录的详情，并刷新月历与今天数据；失败保留输入及错误，可重试。未授权时保存位置提供「Request Access」，被拒时提供「Open System Settings」。

**返回与取消不同**：左上返回或 `Esc` 暂存输入并回到前一页；「取消」放弃草稿，有修改时会先确认。已有一份草稿时新建/编辑另一项，会询问继续旧稿、放弃后开始或取消跳转。切日期只浏览新日期，不改已有草稿的日期、目标或输入；切 tab、收回、离开应用或锁屏后，回到日历列表点「有未保存的日程/待办 · 继续编辑」恢复。`Esc` 先关闭所属日期弹层、菜单或确认，再返回页面；列表里的 `Esc` 收回面板。

**收回与退出**：浏览详情可像列表一样移开收回；正在输入、打开所属菜单/日期弹层或提交时保护操作，离开应用时暂存，锁屏时收回面板。普通退出或菜单中的重启遇到有修改的草稿，会给「保存并退出 / 放弃并退出 / 取消」；有写入正在进行时先等待同一次操作，失败则取消退出。草稿只保留在本次应用运行中，不会自动写进系统日历；崩溃、强制退出或进程结束后不能恢复。

**用文字生成日程/待办**：编辑器（仅新建时）有一个多行原文区；文字先落在输入框本地，**输入不再触发生成**——点「生成」或按 ⌘↩ 才把这段文字连同参考日期/时区发给「设置 → 集成 → AI 模型」里选定的默认模型，不读取其他日历内容。先在「设置 → 集成 → AI 模型」配置；生成行右端的**齿轮**也进入同一页。模型结果填成草稿，仍可修改标题、起止、全天、地点、备注和链接；日期时间按草稿来源时区编辑，异于本机时显示来源时区。只有点保存才写系统记录。默认模型说明不显示具体模型名。

时间或来源不明确时逐项确认日期/时间；取消解析保留原文与保存阻断，可重试，或明确选择「改为手工填写」。生成失败时不再有常驻状态词，只在生成行下方留一行红字「生成失败：<原因>」与「重试」（同排还有「改为手工填写」）。原文改变后旧确认失效；用户手改字段和备注不被迟到结果覆盖。起点明确且原文确实没有结束提示时默认一小时，「周会」不创建重复。待办可保存具体到期时间、备注和链接；无法以来源时区精确保全的 DST 重复时刻会拒绝保存，需改时刻或全天。切页/收回保留本进程草稿；离页不取消正在进行的解析，手动重试若在离页后完成仍可能落在同一稿/修订上。

**会议动作（2026-10-14 简化为「点一下就成」）**：当条记录被认出含会议信息时，**首页**在正文附近出现一个 **22×22 的图标按钮**（面板、详情与卡片是下面那条**一行两键**），**一次点击就是结果**——有可打开的入口就**打开会议**，证据里只有会议号时**复制会议号**（打开被系统拒绝或不可用则**退回复制**，不会谎称已加入）。结果由**图标本身**表达：点击中转圈、成功打勾、失败感叹号（成功态约 1.5 秒后回到常态，只是这一下的反馈，**系统接受打开只表示接受请求，不表示已加入正确会议**）。**时间限制已取消**：不论开始时刻在不在都随时可点，不再有开始时刻闸门；没有真实开始时刻的提醒也不会被补造开始时刻。

**多个入口时不猜**：有一条以上可打开候选时，点一下不直接开会，而是**当场弹出菜单让用户选**（tooltip 写「多个会议入口 · 右键选择」；没有候选可打开时才退回「复制会议号」）。**右键菜单最多 4 项**：复制会议号、在腾讯会议中打开、在华为云会议中打开、复制邀请原文——平台能判定时两条「打开」只留对应那一条（变 3 项），判不出时列两家；**有多个可打开候选时逐条列出每个入口**、不再折叠（条目随候选数增加）。**只有会议号也能按平台打开**：在这一条上选过客户端（菜单里的两家之一）会被记住，之后点一下即按号码拼深链入会（华为深链会带上原文里的入会密码，腾讯深链没有可查依据、不带），没记住时点一下先复制号码。**面板与详情**里换成**一行 `<平台名> <号码或链接>` + 右端「打开 / 复制」两个小键**（判不出平台时只留「复制」，没有任何入口时不画键；**多个候选时只留一个「选择入口」键**，点了弹同一个菜单），这一行的状态位与首页图标同口径，**点了也看得到转圈 / 对勾**。**AI 兜底已移除**：不再向模型发送会议原文，识别完全由本地规则（正则与平台校验）完成。原文华为原生入口被系统拒绝时尝试同来源 HTTPS。普通「会议室/会议资料」不保证显示入口，未知会议平台或路径可能认不出。

## 快速自查

| 现象 | 先看这里 |
|---|---|
| 某个模块「开了却没反应」 | 卡片上的效果行说它在哪出现；带「由上游设置管理」的，真源在上游那一页（面板上的开关是同一个） |
| 首页上少了块 | 「首页组件」节那张卡的开关是不是关了；面板太窄时也会从尾部丢块（条尾有 `＋N`） |
| 首页第一排为什么总是那三块 | 环境带是固定的（音乐 / 前台应用 / 系统读数），顺序按「首页组件」节，位置不参与流 |
| 面板里少了 tab | 「面板组件」节；计时器还多一条——「显示方式」得是「标签页」 |
| 关掉首页面会不会把模块关了 | 不会：模块的另一面照常。只有单面的模块（统计 / 待办 / 通知 / 音乐 / 前台应用）关掉才是真关 |
