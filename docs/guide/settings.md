# 设置参考

设置窗的入口有两处：**菜单栏图标 → 设置**，以及**展开面板右上角的齿轮**（后者需「外观 → 刘海中的设置图标」开着，默认开）。

侧栏按用途分 6 组（组内一页一行），顶部的**搜索框**可以按关键词直接跳到某一页（例如输入「组件」「快捷键」）：

| 分组 | 页 |
|---|---|
| （无节头）核心 | 通用 / 外观 |
| 媒体与显示 | 媒体 / 实时活动 / 锁屏 / 设备 / **组件** |
| 效率 | 计时器 / 剪贴板 / 日历 / 统计 / 终端 / 暂存器 / 取色器 / 下载 / 屏幕助手 / 快捷方式 |
| 系统 | 控制 / 电池 |
| 集成 | 扩展 |
| （无节头）关于 | 关于 |

**本文到处出现的三种标记**：

- 「**默认关**」——装上就是关的，要用得自己去打开；
- 「**（需 X 开）**」——它上面的某一项关着时，这一项会灰掉点不动；
- 「**由上游设置管理**」——这一项的真源在别处（多数在**组件**页那同一张卡上），在这一页改不了。

## 控制

顶部四张卡片是**互斥**的显示方式，点哪张就是哪种：

| 方式 | 默认 | 长什么样 |
|---|---|---|
| **灵动岛**（Dynamic Island） | ✅ 默认 | 音量/亮度/背光直接在刘海处展开一条 |
| **自定义 OSD** | — | 独立的小面板（可换材质与图标配色） |
| **垂直条**（Vertical Bar） | — | 屏幕边缘的一条竖条，可拖拽调值 |
| **圆形**（Circular） | — | 屏幕上的一个圆环 |

**三种方式共用的「控制」开关**：音量 HUD / 亮度 HUD / 键盘背光 HUD（默认都开；键盘背光在开启第三方 DDC 集成后灰显，亮度交给外部 App）。

**自定义 OSD 方式**：材质（Frosted Glass / Liquid Glass / Solid Dark / Solid Light / Solid Auto）、图标和进度颜色（白/白透明/浅灰/深灰/黑/黑透明/自动/自动透明），下面还有一块**实时预览**可以拖动数值看效果。

**垂直条方式**：显示百分比、使用强调色、交互式（可直接拖竖条改值）、材质；位置（左/右 + 屏幕边距）；尺寸（宽 36 / 高 160）与「恢复默认」。

**圆形方式**：显示百分比、使用强调色、彩色音量；尺寸（直径 65 / 线宽 4）与「恢复默认」。

**页面底部（所有方式共用）**

| 项目 | 默认 | 说明 |
|---|---|---|
