2. **S25 多屏**：本机只有一块内建屏。
3. **S17~S20 通知四格语义**：本机无法按需产生一条真实系统通知；**另外** S20 的「一键清除」会清掉岛上当前的 4 条通知且不可复原，无人值守时不做。

**这三类都不影响「本批（p3-widgets）是否成立」的判断**——它们验证的是上游/更早批次的能力。

## 五、本次是怎么跑出来的（可复现）

1. **构建安装**：`sh tools/build.sh --install`（`BUILD SUCCEEDED` → `/Applications/壶中天.app`，0.1.0）。
2. **备份偏好**：`defaults export com.cmeng.gourd - > pre-acceptance-defaults.plist`（另存了 `.dev` 域）。
3. **驱动方式**：`agent.computerUse`（辅助功能树 + 合成事件）。要点：
   - 面板是**非激活 NSPanel**：`getApp({bundle_id})` 直接绑到它；**折叠态点中央槽位那个元素（index 0）即可展开**（不必点坐标）。
   - 设置窗**只有 App 在前台时**才接受输入；窗口一旦被隐藏，像素与点击都拿不到——用 `open -a /Applications/壶中天.app` 把它唤回来。
   - SwiftUI 的 `Toggle` / 侧栏行**不吃 index 点击**，但 `computer.perform_action({target:{type:"element",index}, action:"AXPress"})` 有效；**滑块**用 `AXIncrement` / `AXDecrement`（`setValue` 会被拒）。
   - 设置页**只渲染可见区的控件**（列表外的行只有文字、没有控件且拿不到 action）：要用 `scroll(..., {strategy:"event"})` 把它滚进来再点。
   - 截图证据用 `screencapture -x` + PIL 裁（面板逻辑区 `(179,0,1333,648)`；770 档是 `(371,0,1141,650)`；设置窗 `(406,121,1106,721)`）。
4. **造现场**：Safari 播一个本地音频（`python3` 生成 5 分钟 WAV → `afconvert` → `open -a Safari file://…`）造媒体会话；`say`/`afconvert` 产物跑完即删，Safari 已退出。
5. **还原**：把 S2/S16/S30/S31 改过的键全部写回（`enableScreenAssistant` / `moduleEnableOverrides.shortcuts` / `module.frontapp.maxRecentApps` / 删 `homeBlockOrder`·`panelOrder`·两张名单键），并用 `shortcuts run 外观-深色` 把被 S22 测成浅色的系统外观改回深色。**最终 `defaults export` 与开跑前的备份逐键一致**。
